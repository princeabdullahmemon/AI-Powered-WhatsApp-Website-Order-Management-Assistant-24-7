# AI-Powered WhatsApp & Website Order Management Assistant

An AI-powered customer support and order management system that works through **WhatsApp and a website** using both **text and voice**. Both channels use the same backend workflow for managing customer requests.

### Main Features

- New order creation
- Order cancellation
- Phone number change
- Email change
- Delivery address change
- Order-related complaints
- Text and voice support
- 24/7 automated customer assistance
- Secure OTP verification for sensitive actions

For security, **new orders do not require OTP**, while actions such as cancellation, phone/email/address changes, and complaints require **OTP verification**. The system verifies the customer's order and sends an OTP to the email associated with that order before allowing the requested action.

### Why Use It?

This system can help businesses such as **e-commerce stores, online shops, restaurants, delivery businesses, and other customer-service based companies** reduce manual support work and respond to customers faster.

It can provide support **24/7**, handle repetitive customer requests automatically, reduce response time, improve customer experience, and potentially reduce customer-support costs compared with handling every request manually.
